# Generative-modelling-case-study
Implementation of Generative Adversarial Networks (GANs) for synthetic data, medical imaging (BloodMNIST), cybersecurity (CICIDS2017), and creative sketch generation (QuickDraw pizza dataset).
Generative Modelling Case Study

This repository contains the implementation of Generative Adversarial Networks (GANs) for both synthetic and real-world datasets.

Datasets used:
- Sine-wave and Gaussian synthetic data
- BloodMNIST (medical imaging)
- CICIDS2017 (cybersecurity traffic)
- QuickDraw (pizza sketches)

The code includes model training, evaluation, and visualisation of generated outputs.
